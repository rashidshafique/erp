22Settings rebuilt from the real setting list in the code

Pages map to the keys in app_settings and the 64 process rules. Process rules are split into the area they belong to (Order rules under Sales, Quality rules under Quality, and so on). They write to the same keys as How you work and the presets. Each page opens on the common rules and has a switch to show all of them. Every page shows which permission it needs. Settings that only a developer can change appear read-only on the home page.

21Settings: base structure and custom fields

Every settings page uses the same frame: settings nav on the left, page title + one-line purpose, then content. Custom fields are set per record and can show on the form, as a list column, or on the printed document.
