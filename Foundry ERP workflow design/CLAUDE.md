## Build scripts
`scripts/` holds the Python generators that produce the frames, with `scripts/README.md` listing what each one builds, which are superseded, and the house rules for editing a frame. `build_t28.py` holds the shared tokens and helpers; `fbar.py` holds the filter-bar pieces. Prefer regenerating a frame with its script over hand-editing the HTML.

## Context
- ERP for an ISO 9001 / PPAP foundry. Customers: Tier 1/2 automotive and pump makers.
- Processes: green sand (HPML), no-bake, shell. Metals: grey iron (EN-GJL), SG iron (EN-GJS), aluminium (A356), bronze (CC 491K).
- Currency PKR (Rs), Pakistan-first (FBR/SRB tax, withholding). T1–T15 still show USD; new screens use PKR. No INR or Indian terminology. Neutral names (Meridian Auto Systems, Kovar Pumps, Nordline, Orbis, Stellar).
- Compact record codes: ENQ-, PD-, QT-, SO-, WO-, HT-, PT-, CB-, CR-, CL-, IL-, DN-, NCR-, PPAP-.
- Legibility floor (2026-11-03): smallest text 10.5px, labels 12px+, secondary grey #55585d, tertiary #6b6e73; don't use #8a8d92 or lighter for text.
- Style: calm light SaaS, Helvetica + mono codes, blue accent #2f5fd0, inline styles only, 1280px web cards, 390px phone frames.
- Table style (2026-11-16, from review): uppercase column headers with vertical dividers on a grey ground; zebra body rows (even rows #f7f8f9); record code under the object name when there is no separate code column; one font/size across columns (no mono in cells); Filters and Export = icon-only buttons on the right of the toolbar; the side-panel toggle sits in the last header cell (panel off) or as » inside the panel (panel on). Applied app-wide 2026-11-16 (page CSS in Accounts, Sales, Quality, Settings, Overview). Set in the page `<style>` th/td rules; grid-based list tables (29a/29d) match it by hand.
- Filter pattern (2026-11-17, 29k, from Nomi ref; rolled into the lists same day, defaults per list in the CHANGELOG): list filtering is a chip bar under a full-width search row. + opens an Add-filter menu of the screen's fields; each chip opens an editor matched to its data type — value list/multi-select (status/type/account/currency), number range (on hand/weight/amount), date (presets+custom), text (contains/is/starts with). Chips carry an x; an applied set gains Save + Clear-all and a Saved-filters menu. Replaces the funnel button; Export + panel toggle stay as icons. Demonstrated on 29k; to roll into every list toolbar.
- "Simple mode" = trimmed screens for small jobbing foundries.

`Foundry ERP Styles.dc.html` (25a-25d): graphic style comparison, not a screen area.

`Foundry ERP DS Sample.dc.html` (DS, 2026-11-15): refined design-system sample for review — Foundations (type scale, text/line colour, status = colour + symbol), Controls (buttons incl. one primary; 40px inputs with visible borders/focus/derived/disabled/error, dropdown/date/search; option cards, segmented, toggle, checkbox; filter + amber attention chips), Data (dense 44px list, uppercase sortable headers, selected blue bar, right-aligned tabular numbers, credit-limit flag), and one applied screen (Receive a payment). Proposed tightening of the Helvetica office style; convert screens to it once approved. Not a screen area.
