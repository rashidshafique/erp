29Cores and core boxes

Cores and the core boxes that make them, built from the existing list, record, form and dialog components. The common case — one box, one core, one cavity — stays one short form (29f, layout A); multiple cavities, ownership, stock lots and checks only appear where they are used. Core stock (29g–29i) is a setting, off by default. New codes: CR- core, CL- core lot; CB- core boxes as today. A die is a core box (same screens). Related: the tooling register 18h holds custody for customer tools; a foundry-owned box is also a fixed asset (28c) once capitalised.
