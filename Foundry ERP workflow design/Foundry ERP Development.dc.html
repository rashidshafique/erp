18Pattern development with several tools

A development now holds a list of tools: pattern, core box, gauge, fixture or other. One tool reads like today. Each tool shows a status pill, not its own stage bar; the development's stage bar counts tools under Build and Trial. Create register record lives in the row menu and appears inline only when a tool is Built and not yet registered. Depth comes from rules in 18n. Codes in this turn: PT-0412 pattern, CB-0146 new core box, CB-0127 modified core box, CB-0121 worn core box.

11Pattern development: working new parts through with the customer, and sourcing and charging for the pattern

A development (PD-) opens from an enquiry and stays open until the pattern is approved. It holds points to resolve and a log, both free-form, so it works for any part. Point topics and stages are lists the foundry edits in settings. When approved, it creates the part record 3a and the pattern entry 1f.
