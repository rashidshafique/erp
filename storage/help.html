New customer checklist

From the first call to the first casting poured, in the order the system needs it. Pick a customer to see which steps are already done.

"Foundry-owned" is fine if the foundry made the patterns; set the owner on the pattern's Ownership tab when the customer's own patterns are used.

Steps

  1. The customer. Sales → Customers, or just type the name on the quick order screen. Add address and terms later.
    New customer →
  2. The product. Products → New product: code, name, type, nominal weight. A first revision (0) is made for you when it is needed.
    New product →
  3. The metal. On the product page, Iron grade tab: choose revision 0 and the grade (for example EN-GJL-200), then Set grade. The melting plan cannot size a heat without it.
  4. The patterns. Patterns → New pattern, one per plate. The pattern type is the tooling (for flaskless plates, "Vertical plates (DISA type)"); the mould arrangement (vertically parted, flaskless) follows from it. Then, on the pattern's Ownership tab, mark customer-owned patterns, where they are kept and who holds them.
    New pattern →
  5. Link patterns to the product. On the product page choose "Link a pattern" (or fill the pattern's cavity map). Set the cavities on the plate, and the casting weight if it is known. This is what lets the system count products per mould and match moulds to the order.
  6. The order. Quick flow → New order: customer, product, quantity, due date. It releases the production order at once.
    Tell the system which days the furnace is lit under Settings → Melting days, and orders are checked against them.
    New order → Melting days →
  7. Plan the heat. Quick flow → Next heat shows what to melt, from the pieces and casting weights. Start the heat on the campaign day.
    Next heat →
  8. Plan the moulding. Moulding work lists: add a row for each plate (pattern, station, number of moulds), issue the list, and the moulders start and complete each run. The flaskless line takes one pattern at a time.
    Work lists →
  9. Pour. Record the pour on the pour register for customer work: it attaches the moulds, which is what creates the casting lots for inspection and dispatch.
    Pour register →
  10. After the pour. Thermal and chemistry tests on the heat, the minimum cooling before shakeout, then casting lots, inspection and dispatch.
    Casting lots → Dispatch →

Which way to do it

The system has more than one way to do some jobs. They do not all produce the same records, so choose with care.

JobWaysUse
Enter an orderQuick order · Sales order with contract review · Enquiry and quotation Quick order for repeat or urgent work. The full sales order when quality must sign off first: the quick order skips the contract review.
Record moulds madeWork list · Moulding run page · Bulk run grid · Moulds made grid Plan on a work list. The others record after the fact; do not record the same plates in two of them or the moulds are counted twice.
Record a pourPour register · Moulds poured grid Pour register for customer orders. The grid records the pour but attaches no moulds, so it creates no casting lots.
Start a heatNext heat · Melting plan · New heat by hand Next heat for quick-flow work; the Melting plan when heats are planned days ahead.
Record chargesCharge form · One-click confirm · Fill in past charges · Add missing from the total One-click confirm as the schedule says; "add missing from the total" if charging was not recorded at the time.
